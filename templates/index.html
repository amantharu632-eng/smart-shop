How the Data Mining Pipeline Works

Shopping Recommendation System illustrates Market Basket Analysis. Instead of arbitrary recommendation lists, recommendations are mathematically derived using the Apriori Algorithm over transaction history.

Transaction Preprocessing

Multi-item customer baskets are encoded into binary boolean matrix with mlxtend.TransactionEncoder.

Apriori Pruning & Frequent Itemsets

Iteratively generates $C_k$ candidates and prunes infrequent itemsets using minimum support threshold.

Association Rules (Confidence & Lift)

Extracts strong rules $A \rightarrow B$. Items with highest Lift and Confidence are displayed in real-time!
