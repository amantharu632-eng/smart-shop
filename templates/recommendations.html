The 6-Stage Data Mining Pipeline

Fully Functional • Live Engine
1
Raw Transactions

Customer transactions logged into SQLite and CSV format: {Laptop, Mouse, Bag}.

2
Data Preprocessing

Itemsets are encoded into a binary boolean matrix via TransactionEncoder.

3
Frequent Itemsets

Apriori algorithm generates $C_k$ candidates and prunes any itemset with $\text{Support} < \text{min\_sup}$.

4
Rule Generation

Extracts association rules $A \rightarrow B$ meeting threshold criteria ($\text{Confidence} \ge 15\%$, $\text{Lift} \ge 1.0$).

5
Metric Evaluation

Computes mathematical Support, Confidence, and Lift for each candidate rule.

6
Sorting & Filtering

Rules sorted by descending Lift and Confidence. Redundant or low-correlation items are pruned.

Core Mathematical Formulas

1. Support
Frequency

Probability that a transaction contains both itemsets A and B together.

Support(A → B) = σ(A ∪ B) / N
  • σ(A ∪ B): Transactions containing both A and B.
  • N: Total transactions in the database ({{ total_transactions }}).
2. Confidence
Certainty

Conditional probability that B is purchased given that A is already purchased.

Confidence(A → B) = Support(A ∪ B) / Support(A)
  • Answers: "If a user buys A, how likely is it they will also buy B?"
  • Range: 0.0 to 1.0 (0% to 100%).
3. Lift
Strength

Ratio of the observed joint support to that expected under independence.

Lift(A → B) = Confidence(A → B) / Support(B)
  • Lift = 1: A and B are independent.
  • Lift > 1: Strong positive correlation (Good for recommendations!).
